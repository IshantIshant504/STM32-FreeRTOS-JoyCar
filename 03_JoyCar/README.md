# JoyCar — STM32 FreeRTOS Embedded System

STM32-based autonomous vehicle developed using **Embedded C, STM32, FreeRTOS, PWM motor control, line sensors, ultrasonic sensing and PID control**.

## Project Overview

The JoyCar project focuses on developing a small autonomous vehicle with real-time task management and sensor-based motion control.

The system integrates:

- STM32G431RBT6
- FreeRTOS
- PWM-based motor control
- Infrared line sensors
- Ultrasonic distance measurement
- Servo-based ultrasonic scanning
- PID-based line-following control
- FreeRTOS queues and event flags

## Hardware

- NUCLEO-G431RB
- STM32G431RBT6
- Two DC motors
- Motor driver

- Servo motor

## System Architecture

```text
Line Sensor ──────────────┐
                          │
Ultrasonic + Servo ───────┤       
                          ↓
                    ControlTask
                          │
                          ↓
                     MotorQueue
                          │
                          ↓
                     MotorTask
                          │
                          ↓
                    Motor Driver
```
## FreeRTOS Tasks
### ControlTask

Processes the line-following error and obstacle state and generates the required motor command.

### LineSensorTask

Reads the three line sensors and calculates the line position error.

### ObstacleTask

Processes ultrasonic distance measurements and determines whether the vehicle should operate normally, slow down or stop.

### UltrasonicTrig

Controls the servo scanning sequence and triggers the ultrasonic measurement.

### MotorTask

Receives motor commands and controls the two motors using PWM.

## Inter-Task Communication

FreeRTOS communication mechanisms used in the project include:

- Message queues
- Event flags
- Task priorities

The line sensor data is transferred to the control task through a message queue.

Obstacle conditions are communicated through event flags.

Motor commands are transferred from the control task to the motor task through a message queue.

## Motor Control

The two motors are controlled using PWM signals generated by STM32 timers.

The motor-control interface supports:

- Forward motion
- Reverse motion
- Individual motor speed control
- Motor stopping
## Line Following

Three sensors are used:
```
Left     → PC11
Center   → PC12
Right    → PC10
```

The sensor states are converted into a line-position error used by the control algorithm.

## Obstacle Detection

The ultrasonic sensor is mounted on a servo and scans different angles.

The measured distance is associated with the current scan angle so that obstacle detection can be evaluated in the forward direction.

The control logic uses different responses depending on the measured distance:

- Normal operation
- Reduced speed
- Stop

The stop threshold is configured at 5 cm.

## PID Control

The line-following controller uses PID control to calculate the correction required between the left and right motors.
```
Line Error
    ↓
PID Controller
    ↓
Motor Correction
    ↓
Left / Right Motor Speed
```

The PID parameters are configurable in the source code and can be tuned experimentally.
